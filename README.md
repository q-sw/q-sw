## Qui suis-je ?

Je suis **Lead SRE** chez [S3NS](https://www.s3ns.io), une co-entreprise entre **Thales** et **Google Cloud**. Mon équipe et moi maintenons une plateforme Kubernetes multi-tenant.

Mon travail se concentre sur l'automatisation, l'Infrastructure as Code (IaC) et le développement d'outils pour améliorer l'efficacité opérationnelle. En tant que leas, je veille également à créer et maintenir une documentation claire et complète.

Pendant mon temps libre, j'interviens à l'école d'ingénieurs [CESI](https://www.cesi.fr), où je partage mon expertise sur les méthodologies Cloud, DevOps et SRE.
